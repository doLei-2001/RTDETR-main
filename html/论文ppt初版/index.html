研究背景：自动驾驶目标检测的三大核心挑战

目标检测是自动驾驶感知的底层数据基石，检测精度直接决定后续3D投影与多模态融合的置信度上限。数据集：BDD100K，10万+段驾驶视频，覆盖晴/雨/雪/雾及昼夜，10类标注且约半数存在遮挡。

挑战一：远距离小目标感知难

行人/车辆仅占3-10像素。步长卷积违反奈奎斯特采样定理→高频小目标信号被跳跃跨越→在进入深层网络前发生不可逆的像素级丢失。

挑战二：密集遮挡场景难区分

目标密集排列且相互遮挡，特征高度同质化。注意力ReLU截断→约50%特征交互信息丢失。FFN仅做逐点MLP→完全忽略空间位置。

挑战三：边缘算力与实时性约束

车载平台功耗与算力预算极为有限。标准卷积参数随通道数平方级增长。传统轻量化导致特征表达能力显著退化。

问题诊断：小目标特征损失的根源

问题① 初始下采样阶段 —— 小目标信息不可逆丢失

发生在哪里？RT-DETR的Stem层（网络最前端），输入图像(640×640×3) → 7×7 Conv(stride=2, 通道3→64) → 3×3 MaxPool(stride=2) → 连续两次2倍降采样 = 4倍空间压缩，输出160×160。

后果：仅占3-10像素的远距离行人/车辆，其高频边缘和纹理信号被步长卷积直接跳跃跨越——单个7×7卷积核的感受野即可完全覆盖并超出小目标的范围。根据奈奎斯特采样定理，采样频率低于信号最高频率两倍即发生混叠→微小目标在进入特征金字塔之前已发生不可恢复的像素级丢失，后续所有增强均建立在残缺信息基底之上。

问题② 特征融合阶段 —— 固定权重无法自适应场景

发生在哪里？RT-DETR的CCFM模块（主干网络之后、解码器之前）。主干输出S3(80×80·1/8分辨率)、S4(40×40·1/16)、S5(20×20·1/32)三层特征图，CCFM通过自顶向下+自底向上两条路径对这三层做跨尺度融合。

后果：融合方式为简单通道拼接(Concat)——隐含假设S3/S4/S5三层特征同等重要，每个通道权重为固定1:1:1。但自动驾驶场景中目标尺度剧烈变化——密集小目标场景更依赖浅层S3的空间细节，大目标场景更依赖深层S5的语义抽象——固定权重无法根据场景实际尺度分布动态调整各层贡献度。此外，CCFM仅使用P3~P5三层，缺乏P2(1/4分辨率)的高分辨率特征层，原图3-10px小目标在P3已被压缩至不足1像素。

1在介绍改进方案之前，先诊断清楚小目标特征损失到底发生在哪里。一共两个关键阶段。第一个阶段是初始下采样——RT-DETR的Stem层用7乘7步长卷积加最大池化做4倍降采样，3到10个像素的小目标在这两步之后高频信息就不可逆丢失了。从信号处理角度说，这违反了奈奎斯特采样定理。

2第二个阶段是特征融合——CCFM对主干输出的S3、S4、S5三层做Concat拼接融合，使用固定1比1比1的权重。但在自动驾驶场景中目标尺度剧烈变化，固定权重无法根据场景自适应调整各层贡献。而且CCFM只用了P3到P5三层，缺乏P2的高分辨率信息，小目标在P3已经被压缩到不足一个像素。针对这两个问题，我分别设计了CAS-FD和ACFP两个模块。

方案① CAS-FD：解决初始下采样信息丢失

CAS-FD的作用：生成P2层(1/4分辨率)特征图

它替换了RT-DETR原始的Stem层。Stem是网络的第一道关卡——输入是640×640×3的原始图像，输出是160×160尺寸的P2特征图，后续所有Backbone层都在P2基础上继续处理。

❌ 原来怎么做？（RT-DETR原始Stem）
输入图像(640×640) → 7×7 Conv(stride=2) → MaxPool(stride=2) → P2特征(160×160)

两次暴力降采样，步长卷积的窗口直接"跳过"3-10px小目标区域→高频信息不可逆丢失

✅ 现在怎么做？（CAS-FD）
输入图像 → 三路并行下采样 → SWN逐像素加权 → P2特征(160×160)

三路各自保留不同信息(细节/语义/显著性)→SWN为每个像素学习最优的三路混合比例

三个核心设计

  • ① Dual-Stream Stem：3×3 Conv(局部细节纹理) + 7×7 Conv(大范围上下文) 并行 → 1×1融合，使后续分支建立在更丰富的初始特征上
  • ② 三路并行下采样(信息互补)：
    · DetB细节分支 — Space-to-Depth像素重排(2×2→4通道)，零信息损失
    · SemB语义分支 — 步长DWConv，学习几何形状抽象特征
    · SalB显著性分支 — MaxPool，保留显著响应、抑制低频噪声
  • ③ SWN空间权重网络：1×1+3×3 Conv → Softmax → 为每个空间位置(i,j)生成三路权重{W_sem,W_sal,W_det} → F=Σwᵢ·Fᵢ逐像素自适应融合

效果：小目标密集区域→DetB权重自动调高保留完整像素信息；平滑背景区域→SemB/SalB主导抑制噪声。从源头保护了小目标特征完整性。

讲稿

1CAS-FD替换RT-DETR的Stem层，从源头解决下采样信息丢失问题。核心设计是Dual-Stream Stem预处理、三路并行下采样实现信息互补、以及SWN空间权重网络实现逐像素的自适应融合。其中最关键的是SWN——它不是全局固定权重，而是为每一个空间位置独立生成三个分支的融合权重，小目标区域详情分支权重自动调高，背景区域语义和显著性分支主导。这比原始SRFD的全局Concat有本质区别。

简单说：P2高分辨率特征→SPDConv无损压到P3尺寸→和Y4(高层语义)、P3(原始基础特征)三路一起→AWM为每个通道动态分配融合权重→增强后再经CAFE多尺度精炼→输出给解码器。

三个子模块

  • ① SPDConv无损降维：接收CAS-FD输出的P2(160×160×96) → 2×2空间块重排为4通道(80×80×384) → 1×1 Conv降至目标通道。零信息损失，确保CAS-FD保护的小目标细节在跨尺度传递中不被再次破坏
  • ② AWM自适应加权：接收三路输入——SPDConv增强P2(细粒度细节) + Y4(自顶向下高层语义) + P3(尺度基础表征) → GAP → MLP → Softmax → 为每个通道动态生成融合权重，替代CCFM的固定1:1:1 Concat
  • ③ CAFE多尺度增强(CSP-OmniKernel)：全局(GAP·场景级语义指引) + 大核(31×31各向异性·车道/路口结构) + 局部(1×1·高频纹理)三并行分支 → 仅25%通道经OmniKernel处理，75%恒等映射 → 表达力与效率兼顾

关键策略：不加P2检测头(避免计算量暴增57.2%)，仅在融合阶段通过SPDConv无损引入P2特征。与CAS-FD形成特征保护链：源头保护→传播保护。

讲稿

1ACFP替换原始CCFM，解决特征融合阶段的两个问题：固定权重和缺P2层。通过SPDConv将P2特征无损降维后引入融合，AWM替代固定Concat实现自适应加权，CAFE做多尺度增强。特别注意设计策略是只引入P2特征参与融合、不加P2检测头，这样精度提升的同时计算量不会暴增。ACFP和CAS-FD形成了完整的特征保护链——CAS-FD从源头保护，ACFP在传播中持续保护。

协同机理解析

ACFP中AWM自适应加权的表征上限直接受制于输入特征层的细粒度信息质量。若缺乏CAS-FD在前端对像素信息的无损保护，输入ACFP的P2特征图将携带采样混叠造成的细节缺失→AWM无论如何调整权重，均是在残缺信息基底上进行次优融合。反之仅有CAS-FD而缺ACFP的自适应整合，浅层细节在深层卷积逐级抽象中易被语义信息掩盖。两模块联合构建了从底层物理像素排列到高层抽象语义表征的完整无损传递路径。

问题诊断：AIFI编码器的双重信息瓶颈

瓶颈① ReLU线性注意力的信息截断

标准线性注意力用φ(x)=max(x,0)保证核函数非负性。但当Q与K在某一维度同为负值时，其点积本应为正(负负得正)，ReLU却将其置零→密集遮挡场景中负值承载目标边缘的差分信息与背景抑制信号→约50%的特征交互被硬性截断→相邻相似目标的特征趋于同质化。

瓶颈② FFN的空间感知缺失

原始FFN采用逐点MLP仅在通道维度变换→完全忽略空间邻域关系。经注意力全局聚合后，每个token的原始空间位置特异性已被稀释→逐点FFN无法恢复这种空间判别性。拥堵路段中，空间位置是区分外观高度相似的相邻目标的关键线索。

概念 O(N²)有多贵？S5:20×20=400 tokens→O(400²)=16万次计算；S3:80×80=6400 tokens→O(6400²)≈4100万次(S5的256倍)。所以RT-DETR只敢在S5上做自注意力。O(N)线性注意力通过KᵀV先算再乘Q降复杂度，但代价是ReLU截断丢信息。PolaAttention的贡献：保持O(N)线性复杂度同时恢复被丢的信息。

方案 PASE：极性感知空间增强编码器

PASE替换RT-DETR的AIFI编码器层

发生在混合编码器阶段。接收Backbone输出的S5特征(20×20×512)，经Input Proj(1×1 Conv)降维至256通道后，送入PASE进行全局建模和特征精炼。

子模块① PolaAttention — 应对瓶颈①

  • 极性分离：Q/K各解耦为正负分量Q₊/Q₋、K₊/K₋ → 同号交互M_same=Q₊K₊ᵀ+Q₋K₋ᵀ(找回被丢弃的负值驱动交互) + 异号交互M_oppo=Q₊K₋ᵀ+Q₋K₊ᵀ(互补对比信息)
  • 可学习幂次：power=1+α·σ(W)→对正负分量施加幂次缩放→放大显著特征抑制弱响应→注意力分布从"均匀平滑"变为接近Softmax的尖锐聚焦
  • 利用结合律先算KᵀV→维持O(N·d²)线性复杂度

子模块② ACGF — 把FFN从"逐点变换"改成"空间-内容协同精炼"

  • 双输入：主输入X_attn(全局上下文)+辅助输入X_orig(原始空间信息)→空间分支从X_orig提取位置信息注入主分支
  • 双向门控：正向G_fwd=GELU(x')⊙x₂(空间引导内容)+反向G_bwd=GELU(x₂)⊙x'(语义校正空间)→α·G_fwd+β·G_bwd
  • 通道自适应：g=σ(W_g)每个通道独立学习门控强度→最终=g⊙F_bi+(1−g)⊙x₂弹性融合
讲稿

1PASE用两个子模块分别应对两个瓶颈。PolaAttention通过极性分离策略将Q和K解耦为正负分量，构建同号和异号双路注意力计算，找回被ReLU丢弃的负值驱动交互信息。可学习幂次函数使注意力分布从均匀平滑变为接近Softmax的尖锐聚焦。ACGF通过双输入设计将原始空间信息注入被注意力稀释的语义特征，双向门控实现空间与内容的互调制。

概念 FFN是什么？MLP又是什么？Transformer的每一层编码器由两个子层组成：①自注意力层(建模全局关系) + ②FFN前馈网络层(对注意力输出做进一步特征变换)。FFN内部就是一个MLP(多层感知机)——本质是两层全连接：先把通道数放大4倍(256→1024)做非线性激活(ReLU/GELU)，再压回原通道(1024→256)。"逐点"的意思是：对特征图上每个空间位置独立做相同的通道变换——只看自己这256个通道的值，不看周围邻居。好处是简单高效，坏处是完全不管空间位置关系。
为什么在密集场景下这是个问题？自注意力层已经把全局信息混合了→每个位置的空间特异性被稀释→此时逐点FFN再来一遍"只看自己不看他"→空间位置线索彻底丢失→外观相似的相邻目标无法区分。ACGF的解决思路：给FFN加一个"空间输入"(原始特征，空间位置信息还在)，再通过双向门控让空间信息指导内容筛选、内容反过来校正空间→恢复被稀释的空间判别性。

矛盾：功能模块带来精度，但推理速度骤降

指标基线+三个功能模块变化

根源：ResNet-18主干的参数冗余

ResNet-18有4个stage(Layer1~4)，每个stage含2个BasicBlock→共8个Block。每个BasicBlock含2个标准卷积层→共16个标准卷积。每个标准卷积C_in·C_out·K²参数 → 以64通道3×3核为例：64×64×9=36,864参数/层。问题：标准卷积将空间滤波与通道融合耦合在一起，每个输出通道都要一个完整的K×K×C_in三维卷积核→参数量随通道数平方级增长→大量参数冗余。

策略：不削弱功能模块(那是精度的保障)，把16个标准卷积全部换成更省参数的轻量化算子。

1第三部分解决精度与速度的矛盾。三个功能模块引入后精度提升了2.7个点但速度从136帧降到76帧。瓶颈根源在于ResNet-18的16个标准卷积层——每个标准卷积将空间滤波和通道融合耦合在一起，参数存在大量冗余。解决思路是不削弱功能模块，转而对存在参数冗余的主干网络进行轻量化重构。

方案 LDC：三步实现精度保持型主干轻量化

LDC替换ResNet-18所有8个BasicBlock

LDC = C2f_DCMB，嵌入在ResNet-18的Layer1~4中，每个stage原来的2个BasicBlock→2个LDC模块。

第1步 换算子：标准卷积 → 深度可分离卷积

把空间滤波(K×K滑动)和通道混合(加权求和)拆开→先对每个通道单独K×K滤波(DWConv) + 再用1×1做通道融合(PWConv)。64通道3×3核：36864→4672参数，减少87%。16个卷积层全这样换→主干参数大降。

第2步 补表达力：单DWConv → MBDC三路并行+DKW

单一DWConv感受野固定→MBDC用三个不同形状DWConv并行：方形K×K(局部纹理)、横向带状1×M(车道线/水平长距)、纵向带状M×1(垂直关系·互补)。DKW：GAP→1×1 Conv→Softmax→自适应分配三路权重w₁,w₂,w₃。

第3步 再省计算：CSM通道分割

输入特征通道均分为两组(C/2各进一个MBDC并行处理)→拼接+1×1 PWConv跨组融合。通道减半→深度卷积计算量再降约50%。
