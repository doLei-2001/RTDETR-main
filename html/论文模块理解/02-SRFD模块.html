🔄 SRFD / CAS-FD: 内容感知选择性特征下采样

解决传统步长下采样在小目标检测中的信息丢失问题，从特征提取源头保护微小目标像素级信息

从问题出发：为什么需要改进下采样？

🔴 核心问题：奈奎斯特采样定理被违反

根据信号处理中的奈奎斯特采样定理，当采样频率低于信号最高频率的两倍时，会引发严重的采样混叠效应。在深度学习中：

  • 远距离小目标（行人、骑行者）在图像中仅占 3-10个像素
  • 这些目标表现为 高频信号（边缘、纹理细节）
  • 步长卷积/池化的跳跃采样直接跨越这些微小区域
  • 结果：微小目标像素级信息在特征提取初期不可逆丢失

❌ Baseline下采样路径

7×7 Conv (stride=2) → 3×3 MaxPool (stride=2) → 连续BasicBlock下采样

  • 激进的大步长大核卷积
  • 小目标信息被"跨越"而过
  • 特征同质化 + 背景噪声主导

✅ CAS-FD改进思路

三路并行下采样 + 空间自适应权重融合

  • 细节分支：像素重排，零信息损失
  • 语义分支：步长卷积，保持抽象感知
  • 显著性分支：最大值筛选，抑制噪声
  • 空间权重：为每个像素动态分配混合比例

🎯 答辩要点："Baseline使用7×7步长卷积+MaxPool进行快速下采样，对于仅占3-10个像素的小目标而言，这种激进的下采样直接导致其像素级信息不可逆丢失。SRFD虽引入了三路并行下采样，但这种多路融合仍采用全局固定的通道拼接，在大背景小目标的航拍图像中大面积的背景噪声主导了融合权重，导致小目标特征被平均化淹没。于是我提出了CAS-FD：一方面增加Dual-Stream Stem来丰富预处理阶段的特征表达，一方面引入空间权重网络SWN为每个像素动态分配三路权重，使小目标区域的细节分支权重自动调高，背景区域的显著性和语义分支权重占主导，从而实现逐像素的内容感知融合。"

改进：从SRFD到CAS-FD

SRFD的局限

  • 三路融合使用简单的通道拼接 → 固定权重
  • 大背景小目标图像中，全局权重被大面积背景主导
  • 占比小的小目标特征被平均化淹没
  • 无法为每个空间位置生成差异化权重

CAS-FD的改进

  • 双卷积感知预处理：Dual-Stream Stem
  • 空间自适应融合：不再使用固定权重Concat
  • SWN：为每个像素生成专属的三路混合权重
  • 三路从"同等贡献" → "内容感知贡献"

空间权重网络深入解析

💡 为什么要用空间权重？

在自动驾驶图像中，不同区域对三种下采样策略的需求不同：

  • 小目标区域（远端行人、车辆）：需要 DetB 保持完整像素信息 → 权重偏重DetB
  • 大目标区域（近处车辆）：需要 SemB 提取上下文语义 → 权重偏重SemB
  • 平滑背景区域（路面、天空）：需要 SalB 抑制噪声 → 权重偏重SalB
# SWN 前向传播：为每个像素生成三路权重 def forward(self, conv_feat, max_feat, cut_feat): # 1. 三路特征在通道维度堆叠 stack = torch.cat([conv_feat, max_feat, cut_feat], dim=1) # [B, 3C, H, W] # 2. 轻量级卷积网络 + Softmax 生成空间权重 # 权重图 W 形状：[B, 3, H, W] # W[:,0,:,:] → conv权重, W[:,1,:,:] → max权重, W[:,2,:,:] → cut权重 spatial_weights = self.spatial_weight_net(stack) # 3. 逐像素加权融合 (element-wise) fused = (conv_feat * spatial_weights[:, 0:1, :, :] + max_feat * spatial_weights[:, 1:2, :, :] + cut_feat * spatial_weights[:, 2:3, :, :]) return self.final_proj(fused) # 1×1 Conv 最终投影

✅ 本章核心结论

  • CAS-FD在特征提取源头保护了小目标像素级信息
  • 三路并行实现了信息互补：语义+显著性+细节的全面覆盖
  • 空间权重网络实现了逐像素的自适应融合，而非全局固定权重
  • 与ACFP模块形成特征保护链：源头保护 + 传播保护 = 完整的小目标特征保留
